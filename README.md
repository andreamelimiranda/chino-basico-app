# Chino Básico

Primera versión de una PWA para aprender mandarín desde el celular.

## Incluye
- 8 palabras básicas con pinyin y significado.
- Pronunciación usando la voz china del dispositivo/navegador.
- 6 frases para una conversación inicial.
- Mini-quiz de 5 preguntas.
- Práctica libre de escritura para el carácter 你.
- Progreso guardado en el navegador.
- Soporte PWA/offline básico.

## Publicarla en GitHub Pages
1. Crea un repositorio en GitHub.
2. Sube todos los archivos de esta carpeta manteniendo la estructura.
3. En GitHub: Settings > Pages.
4. En "Build and deployment", elige "Deploy from a branch".
5. Selecciona `main` y `/ (root)`.
6. Abre la URL que GitHub te entregue.

## Instalar en celular
- Android/Chrome: abre la URL y elige "Instalar aplicación" o "Agregar a pantalla de inicio".
- iPhone/Safari: Compartir > Agregar a pantalla de inicio.
